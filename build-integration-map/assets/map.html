    Como usar

    Clique num nó para abrir a ficha. Arraste o fundo para mover, scroll para zoom, arraste um nó para reposicionar. / foca a busca, que lista as opções conforme você digita — ↑ ↓ andam na lista, Enter abre. 0 ajusta, Esc limpa. Com um nó selecionado, os três botões do topo respondem o que quebra, do que depende e por onde o dado passa.
